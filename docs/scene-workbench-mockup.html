External controls
MIDI → the faders / Simple Desk. Switch to Edit, select a fader (or the Workbench), open External controls → add a controller → hit the 🪄 auto-detect wand → wiggle the knob. Universe/Channel pulse red until the MIDI lands. (Simple Desk itself is mouse/keypad; VC Sliders are its MIDI-mappable twin and feed the same DMX the Workbench captures.)
Include / exclude channels. The Int / Col / Pos / Beam buttons on the Workbench (and in Settings) flip whole channel groups in/out of the save — excluded faders grey out. That maps to the engine’s channelMask; the fixture set maps to selectedFixtures.
Pick another scene. The Editing ▾ picker on the Workbench loads a stored Scene onto the live desk; Update writes it back, Save New clones it.
