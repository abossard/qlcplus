HUE effects

A visual booklet of native-rendered effects and their main mode variants. Compare static posters, then play one preview at a time.

Synthetic input. These offline captures show a specified layout, palette and input sequence. They do not show live fixtures or establish musical preference, hardware output or runtime acceptance.

Some previews contain flashing light. Nothing animates on page load. Flashing previews have a warning beside their Play control.

Choose Play to animate. Use Stop or Escape to return to a static poster. GIF loops may reset effect history or animation phase.

        Modes and saved configurations
        
Artistic, Reference and named LedFx modes select built-in behavior variants. To keep several configurations of one script, create separate named HUEMatrix functions.

        
A saved .qxw workspace preserves mode, parameters, palette and timing. Running particles, history buffers and animation phase do not persist.

    Duration and FPS describe the sampled simulation, not application performance. Playback speed 1× is real-time; 0.5× doubles the GIF's playback duration. The GIF already includes this scaling. Screen scaling, GIF color quantization and omitted frames can hide detail or change the appearance of rapid pulses.
