## Findings left unchanged

- `engine/src/rgbscriptv4.cpp` and `engine/src/rgbscriptv4.h` use `fixed` for the literal 32-band script registration constant, not for low/mid/high cut points.
- `docs/audio-monitor-panel.md` says the monitor panel registers a fixed 32-band count while open; it does not describe fixed band cuts.
- `ledfx_compat.js` correctly documents log-frequency crossover ratios and derived split indices.
- `audiocapture.cpp/h` comments correctly describe log-spaced bands and computed crossover bins.
- `vcaudiotriggers.cpp/h` references spectrum bars and band display plumbing without claiming linear spacing or fixed cuts.
