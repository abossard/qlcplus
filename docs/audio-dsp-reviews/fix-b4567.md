# Fix B4-B7 — AudioAnalyzer DSP formulas

## Summary

Fixed the AudioAnalyzer formula deviations identified as B4, B5, B6, and B7.

## Changes

- **B4 spectral flatness on silence**
  - Silent frames now set `spectralFlatness = 1.0`.
  - This matches the contract that silence has no spectral shape and is treated as maximally flat.

- **B5 spectral flux normalization**
  - `spectralFlux` is now normalized by `Σ|M_k[t-1]|` over the previous frame magnitudes.
  - The denominator is clamped with `1e-10` for silence-to-signal transitions to avoid division by zero.

- **B6 spectral flux frequency range**
  - Flux now uses only bins covering 40 Hz through 5000 Hz:
    - low bin: `ceil(40 * fftSize / sampleRate)`
    - high bin: `floor(5000 * fftSize / sampleRate)`
  - This aligns flux with centroid, rolloff, flatness, and the canonical analyzer range.

- **B7 adaptive noise floor law**
  - Noise floor initialization changed from `-96 dB` to `-60 dB`.
  - Quieter frames snap down instantly to `rmsDb`.
  - Louder frames rise at a maximum of `+6 dB/s` using `audioDtMs`:
    `noiseFloor += min(6.0 * audioDtMs / 1000.0, rmsDb - noiseFloor)`.

## Tests

Updated `audioanalyzer_test` expectations for silent-frame flatness and added spectral-flux formula coverage:

- normalized positive delta (`1 / 2 = 0.5`)
- exclusion of bins above 5000 Hz
- existing onset/steady-state flux behavior
- updated noise-floor comments for the +6 dB/s release law
