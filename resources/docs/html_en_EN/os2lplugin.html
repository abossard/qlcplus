OS2L plugin

Introduction

The OS2L plugin allows direct communication between QLC+ and an OS2L capable host.
OS2L specifications can be found at: http://os2l.org
At the moment the main OS2L host supported is Virtual DJ.
QLC+ OS2L plugin will work either on the same host (127.0.0.1) or on a different host with an OS of your choice (Windows, macOS, Linux)

New Features

The enhanced OS2L plugin now includes:

  • Automatic Service Discovery: Uses Bonjour/mDNS to automatically discover VirtualDJ and other OS2L-compatible software on your local network
  • Enhanced Logging: Displays all incoming OS2L messages with detailed information in the console output
  • Song Metadata: Extracts and logs song information including name, artist, album, BPM, key, elapsed time, duration, genre, and more
  • Bidirectional Communication: Support for sending feedback messages back to VirtualDJ (experimental)
  • Beat Detection: Receives and processes beat messages for synchronization

Configuration - Virtual DJ

Step 1: Configure VirtualDJ
First and foremost, you need to tell VDJ where to send OS2L messages.
Open VDJ settings, go to the 'Options' panel and type 'os2l' in the top search box.
Modify the 'os2lDirectIp' field by setting the IP:port where VDJ can reach QLC+. For example, '127.0.0.1:9996' should work if QLC+ runs on the same (Windows) PC of VDJ.
Once done, restart VDJ.

Step 2: Enable OS2L in QLC+
Now go to QLC+, enable the OS2L plugin on any universe (Input/Output panel). If you have set a specific port in VDJ, open the OS2L configuration dialog and set the same port there.
Once done, QLC+ will start receiving signals from VDJ (joystick icon will blink beside the Universe box)

Step 3: Check the logs
If you run QLC+ with the -d flag (debug mode), you will see detailed logs of all OS2L messages:

  • Service discovery announcements when VirtualDJ is detected on the network
  • All JSON message fields and their values
  • Song metadata when tracks change (song name, artist, BPM, key, etc.)
  • Beat messages for synchronization
  • Button and command events

Automatic Service Discovery (Bonjour/mDNS)

The plugin now automatically discovers OS2L services on your local network using Bonjour/mDNS. When VirtualDJ or another OS2L-compatible application starts on your network, the plugin will detect it and log the discovery. This makes setup easier as you don't need to manually configure IP addresses.

Look for messages like:
[OS2L Discovery] Found OS2L service announcement from 192.168.1.100
[OS2L Plugin] Auto-discovered service: OS2L@192.168.1.100 at 192.168.1.100:9996

Song Metadata Display

When VirtualDJ sends song information, the plugin will log all available metadata: 

[OS2L] ==================== SONG METADATA ====================
[OS2L] Song Name: Shape of You
[OS2L] Artist: Ed Sheeran
[OS2L] Album: ÷ (Deluxe)
[OS2L] BPM: 96.0
[OS2L] Key: 8B
[OS2L] Elapsed: 32.5 seconds
[OS2L] Duration: 233.7 seconds
[OS2L] Deck: 1
[OS2L] ======================================================
This information can be used to trigger lighting cues based on song changes, BPM, or other metadata.
