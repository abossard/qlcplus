OS2L plugin

Introduction

The OS2L plugin allows direct communication between QLC+ and an OS2L capable host.
OS2L specifications can be found at: https://os2l.org
At the moment the main OS2L host supported is VirtualDJ.
QLC+ OS2L plugin will work either on the same host (127.0.0.1) or on a different host with an OS of your choice (Windows, macOS, Linux).

Automatic Discovery (macOS)

On macOS, the plugin automatically registers QLC+ as a Bonjour service (_os2l._tcp) using the native dns_sd API.
This means VirtualDJ can find QLC+ when its OS2L mode is set to Auto — no manual IP configuration is needed.

Setup:

  1. In VirtualDJ settings, search for os2l and set os2lDirectIp to Auto (or leave it empty).
  2. In QLC+, enable the OS2L plugin on any universe (Input/Output panel).
  3. VirtualDJ will discover QLC+ via Bonjour and start sending messages automatically.

Configuration — Manual (all platforms)

If Bonjour is unavailable (Linux, Windows) or you prefer manual configuration:

  1. Open VDJ settings → Options → type os2l in the search box.
  2. Set os2lDirectIp to the IP:port where VDJ can reach QLC+ (e.g. 127.0.0.1:9996 for same machine).
  3. Restart VDJ.
  4. Enable the OS2L plugin on a QLC+ universe.
  5. The joystick icon will blink when messages are received.

Song Metadata

When VirtualDJ sends a song event (see OS2L spec and VirtualDJ OS2L wiki), the plugin logs all available fields: 

[OS2L] ==================== SONG METADATA ====================
[OS2L] Song Name: Shape of You
[OS2L] Artist: Ed Sheeran
[OS2L] BPM: 96.0
[OS2L] Key: 8B
[OS2L] ======================================================
Supported fields: name, artist, album, genre, year, remix, status, bpm, key, elapsed, duration, deck.

Viewing Logs

Run QLC+ with the -d flag to see all OS2L messages in the console: 

qlcplus5 -d
