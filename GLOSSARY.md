# QLC+

Language for lighting performances and their recorded control instructions.

## Language

**Show**:
A timed performance containing Functions and control instructions. Its playback
meaning is the same whether its content was authored or captured through recording.
_Avoid_: Recorded Show as a separate kind of performance

**Performance recording**:
Capturing accepted operator control instructions as content of a Show.
_Avoid_: DMX output recording, a separate playback mode

**Palette**:
A named, reusable capability such as color or position that can be applied to
fixtures.

**Widget preset**:
A saved choice belonging to a Virtual Console control. It can contain control
values and a choice of Functions or fixture heads.
_Avoid_: Palette when referring to a widget's saved choice

**Function binding**:
The Function assigned to a Virtual Console control.
